# APCSA Freedom Project
by **Kyle Lin**

## Context
I am a student at [HSTAT](https://www.hstat.org/) in the [Software Engineering Program](https://hstatsep.github.io/). The "Freedom Project" for AP Computer Science A is a year-long project all about making anything using technology.

For my project, I chose to collaborate with my peer Joe to create a game that would positively impact adolescents by allowing them to have an opportunity to hone skills while keeping their focus. I created a circle-clicking game while my partner Joe created a reaction time game using Swift, with the main purpose of providing a measurable gameified metric for adolescents to access during downtime: studying or whatnot.

## Implications
##### PROS
* The gameplay is fast and doesn't take a lot of time
* Exercises hand-eye coordination skills
* Measurable progress each playthrough
* A quick de-stress game/tool
##### CONS
* Limited in difficulty and variety
* Increased use of screen time
* May be buggy and inaccurate
* Unavailable to those without devices
